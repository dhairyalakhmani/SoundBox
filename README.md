🎵 Simple Soundboard — Web Development Mini Project

A fun, interactive, and beginner-friendly Web Development Semester Project that demonstrates how to use the JavaScript Audio API to play sounds directly in the browser.

This project focuses on clean UI, responsive interaction, and fundamental DOM manipulation — perfect for learning core web concepts while building something enjoyable.

🚀 Project Overview

The Simple Soundboard is a lightweight web app where users can click buttons to instantly play different sounds.
It includes a minimal interface with intuitive controls and smooth playback using:

new Audio() Web API

Basic DOM events

Simple grid-based layout

One-way interaction (user clicks → audio plays)

🎧 Features at a Glance

🎚️ Volume Slider — Adjust sound intensity in real time

🔇 Mute Button — Instantly silence all sounds

🐶 👏 🎉 😂 8 Sound Buttons — Dog bark, clap, pop, laugh & more

⚡ Instant Playback — No lag, no loading

📱 Responsive Layout — Works on laptop & mobile

🎨 Simple & Clean UI — Easy to understand, easy to use

🧠 What This Project Teaches

This project is designed with learning in mind — ideal for Web Development beginners:

🎵 Audio API Fundamentals — Creating and controlling audio with new Audio()

🖱️ Event Handling — Button click events and user interaction

🧩 DOM Manipulation — Linking UI elements with JS functions

🏗️ HTML/CSS Layouting — Grid-based UI design

🎛️ State Management Basics — Volume, mute, and playback controls

🧪 Debugging Practice — File paths, audio loading, browser behavior

🛠️ Technologies Used

HTML5 (structure)

CSS3 (styling + grid layout)

JavaScript (Vanilla) (Audio API + logic)
